# Agent instructions (Codex and other coding agents)

This repository's working rules are in **[CLAUDE.md](CLAUDE.md)**. They apply to every coding agent, not only Claude Code.
Read it first, then:

1. [docs/session-handoff.md](docs/session-handoff.md): current state, branch claims, next action.
2. [docs/claude-memory/MEMORY.md](docs/claude-memory/MEMORY.md): working rules learned in past sessions.
3. [docs/project-recovery/AI_AGENT_CONTINUATION_GUIDE.md](docs/project-recovery/AI_AGENT_CONTINUATION_GUIDE.md): load
   order, the dangerous-commands list, and where to change what.

The non-negotiables, in short:
- Never `npx supabase db reset` or `test db` the main local database. Database tests use the disposable test stack.
- Never deploy, change hosted settings, merge dependency updates, force-push, or rewrite history without the owner's
  explicit word.
- Never invent data; an AI is never the reviewer.
- No AI attribution lines in commits or PRs.

`code/AGENTS.md` is generated by Next.js and covers only its own docs warning.
